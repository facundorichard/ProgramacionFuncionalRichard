# Programación III - Trabajo Práctico: Programación Funcional

## 📘 Descripción

Este proyecto corresponde al **Trabajo Práctico de Programación Funcional** 
El objetivo es practicar el uso de **Streams**, **expresiones lambda** y **Collectors** en Java para procesar colecciones de datos de forma **declarativa e inmutable**.

## 🧩 Contenido del proyecto

Se desarrollan distintos casos prácticos aplicando programación funcional a diferentes clases:

1. **Alumno(nombre, nota, curso)**

   * Filtrar aprobados (nota ≥ 7) y mostrar nombres en mayúsculas.
   * Calcular promedio general.
   * Agrupar por curso.
   * Obtener los 3 mejores promedios.

2. **Producto(nombre, categoría, precio, stock)**

   * Listar productos con precio > 100, ordenados descendentemente.
   * Agrupar por categoría y calcular stock total.
   * Generar reporte textual con nombre y precio.
   * Calcular promedio general y por categoría.

3. **Libro(título, autor, páginas, precio)**

   * Listar libros con más de 300 páginas, ordenados alfabéticamente.
   * Calcular promedio de páginas.
   * Agrupar por autor y contar libros.
   * Obtener el libro más caro.

4. **Empleado(nombre, departamento, salario, edad)**

   * Listar empleados con salario > 2000.
   * Calcular salario promedio general.
   * Agrupar por departamento y sumar salarios.
   * Obtener los 2 empleados más jóvenes.

## 🛠️ Tecnologías utilizadas

* **Java 17+**
* **Streams API**
* **Collectors**
* **Expresiones Lambda**

## 🚀 Objetivos de aprendizaje

* Aplicar operaciones de **mapeo, filtrado, reducción y agrupación**.
* Reemplazar código imperativo por **enfoques declarativos** más claros.
* Generar **reportes funcionales y estadísticas** usando Streams.
